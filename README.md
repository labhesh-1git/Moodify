
# 🎧 Moodify - Chrome Extension

**Tab title se mood detect → Perfect YouTube music!** 🇮🇳

[![Chrome Extension](https://img.shields.io/badge/Chrome-Extension-4285F4)](https://chrome.google.com/webstore)
[![JavaScript](https://img.shields.io/badge/JavaScript-ES6-F7DF1E)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

## ✨ Features
- ✅ **15+ moods**: Gaming, Sad, Rain, Coding, Party, Travel...
- ✅ **100% accurate** priority matching 
- ✅ **Stable 2026** YouTube links
- ✅ One-click music in new tab
- ✅ Beautiful gradient UI

## 🎮 Demo
"python code" → 💻 Coding beats
"rain mumbai" → 🌧️ Rain sounds
"sad story" → 💔 Sad piano 2026
"party time" → 🎉 DJ remix

## 🚀 Install (30 seconds)
1. `chrome://extensions/`
2. **Developer mode** ON
3. **Load unpacked** → Select folder
4. Pin extension → Test!
